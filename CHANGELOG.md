# Changelog

## 0.6.0

- The server reads the game window, so the addon no longer takes a screenshot on every send.
- Sends are spread over several frames.
- Bag tooltips are cached for 2 minutes.
- `/seer status` shows what the last send cost.
- Simpler Windows install steps.

## 0.5.4

- Tools show how old each section is.
- XP and durability changes are sent.
- `get_guide` shows Polestar's step numbers.

## 0.5.3

- Fixed trainer ranks and status.

## 0.5.2

- Says in chat when a newer Seer exists.

## 0.5.1

- Added AtlasLoot, SkillUp Forever, Forever Leveling BiS, Nova Instance Tracker and DataStore.

## 0.5.0

- Added Auctionator, Questie, Polestar, Pawn and What's Training.
- Added the last fight and map position.
- Sends are compressed.
